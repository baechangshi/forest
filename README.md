# 끝없는 숲

끝없이 이어지는 로우폴리 숲을 1인칭으로 걷는 웹 공간입니다. 모바일과 PC에서 모두 동작합니다.

- **끝없는 숲:** 걷는 방향으로 숲이 계속 생겨납니다. 시드가 고정돼 있어서 모든 사람이 같은 숲을 걷습니다.
- **시간·날씨:** 숲의 하루는 실제 20분입니다. 낮, 노을, 밤이 지나가고 맑음, 안개, 비가 바뀝니다. 실제 시계를 기준으로 하기 때문에 접속한 사람 모두가 같은 하늘을 봅니다.
- **발견:** 오두막, 연못, 돌무리, 버섯 고리, 석등, 벤치, 고목, 이정표가 있고 사슴, 토끼, 새 떼를 만날 수 있습니다.
- **흔적:** 다른 사람이 최근 이틀 동안 걸은 길이 빛나는 발자국으로 보입니다. 남겨진 한 줄 메시지는 30일 동안 그 자리에 있습니다. 이 기능은 Firebase를 연결해야 켜집니다.
- **구글 로그인 (선택):** 걷기와 흔적 보기는 로그인 없이 됩니다. 메시지를 남길 때만 구글 로그인이 필요합니다. 로그인하면 내가 남긴 메시지가 민트빛으로 표시되고 직접 지울 수 있습니다. 또 어느 기기에서 들어와도 마지막으로 걷던 자리에서 이어 걷습니다.
- **기록:** 걸은 거리, 숲에 머문 시간, 발견한 수가 브라우저에 저장됩니다. 다시 들어오면 마지막 위치에서 이어서 걷습니다.

## 조작

| | 모바일 | PC |
|---|---|---|
| 걷기 | 화면 왼쪽을 누른 채로 밀기 (멀리 밀면 빨리 걸음) | W A S D, ↑ ↓ |
| 둘러보기 | 화면 오른쪽을 드래그 | 마우스 드래그, ← → 또는 Q E |
| 빨리 걷기 | 조이스틱을 멀리 밀기 | Shift |

## 1. GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만듭니다. 이름은 예를 들어 `forest`로 하고, Public으로 만듭니다.
2. 이 폴더의 파일을 모두 올립니다. `.nojekyll`도 함께 올려야 합니다.
   - 웹에서 올릴 때: 저장소에서 **Add file → Upload files**를 누르고 폴더 안의 내용을 끌어다 놓습니다.
   - git으로 올릴 때:
     ```bash
     git init && git add . && git commit -m "끝없는 숲"
     git branch -M main
     git remote add origin https://github.com/<아이디>/forest.git
     git push -u origin main
     ```
3. 저장소의 **Settings → Pages**에서 Source를 **Deploy from a branch**로, Branch를 **main / (root)**로 정하고 저장합니다.
4. 1~2분 뒤 `https://<아이디>.github.io/forest/`에서 열립니다.

> Firebase를 연결하지 않아도 숲은 그대로 동작합니다. 이때는 혼자 걷는 모드라 메시지가 이 기기에만 저장됩니다.

## 2. Firebase 연결 (흔적 공유)

1. [Firebase 콘솔](https://console.firebase.google.com)에서 **프로젝트 추가**를 누릅니다. Google 애널리틱스는 꺼도 됩니다.
2. **빌드 → Authentication → 시작하기 → 로그인 방법**에서 두 가지를 켭니다.
   - **익명:** 로그인하지 않은 사람의 발자국을 남기는 데 씁니다.
   - **Google:** 프로젝트 지원 이메일을 고르고 저장합니다.

   그다음 **Authentication → 설정 → 승인된 도메인**에 `<아이디>.github.io`를 추가합니다. 빠뜨리면 구글 로그인이 실패합니다.
3. **빌드 → Firestore Database → 데이터베이스 만들기**를 누릅니다. 위치는 `asia-northeast3 (서울)`을 고르고 **프로덕션 모드**로 시작합니다.
4. Firestore의 **규칙** 탭에 이 폴더의 `firestore.rules` 내용을 붙여 넣고 **게시**합니다.
5. **프로젝트 설정(톱니바퀴) → 일반 → 내 앱**에서 **웹 앱(</>)을 추가**하고, 화면에 나오는 `firebaseConfig` 값을 `js/config.js`에 붙여 넣습니다.
6. 바뀐 `js/config.js`를 GitHub에 다시 올립니다. 시작 화면에 초록 점과 함께 "다른 이들의 흔적이 보이는 숲"이 표시되면 연결된 것입니다.

**선택 1. 오래된 데이터 자동 삭제 (권장)**

Firestore의 **TTL** 메뉴에서 정책을 두 개 추가합니다.

- 컬렉션 `trails`, 필드 `exp`
- 컬렉션 `messages`, 필드 `exp`

이렇게 하면 기한이 지난 발자국과 메시지가 저장소에서도 지워집니다.

**선택 2. 키 보호**

Google Cloud 콘솔의 **API 및 서비스 → 사용자 인증 정보**에서 브라우저 키의 HTTP 리퍼러를 `https://<아이디>.github.io/*`로 제한합니다.

`config.js`의 값은 웹앱용 공개 식별자라서 공개 저장소에 올려도 괜찮습니다. 실제 데이터 보호는 보안 규칙이 맡습니다. 무료 Spark 요금제로 충분합니다.

### 로그인과 이어 걷기

- **로그인 방식:** 팝업 방식입니다. 홈 화면에 추가한 앱 모드(특히 iPhone)에서는 팝업이 막힐 수 있습니다. 그때는 Safari나 Chrome에서 직접 열면 됩니다.
- **저장되는 내용:** 로그인한 사람의 위치, 바라보는 방향, 걸은 거리와 시간, 발견 기록이 Firestore `users/{uid}`에 저장됩니다. 움직였을 때만 45초마다 저장하고, 페이지를 닫을 때도 저장합니다.
- **기기 사이의 기록:** 다른 기기에 더 최근 기록이 있으면 그 자리로 이동합니다. 발견 기록은 두 기기의 것을 합칩니다.
- **화면에 보이는 정보:** 숲에는 이름과 이메일이 표시되지 않습니다. 메시지에는 계정 식별자(uid)만 함께 저장됩니다.

### 메시지 관리

- **클라이언트에서 막는 것:** 욕설·비하 표현, 링크, 전화번호, 40자 초과, 하루 5개 초과, 30초 안에 연속 작성
- **서버 규칙에서 막는 것:** 구글로 로그인하지 않은 사람의 메시지 작성, 형식이 다른 데이터, 41자 이상의 글, 링크, 다른 사람 글의 수정·삭제
- **보는 사람이 할 수 있는 것:** 마음에 들지 않는 메시지는 **숨기기**를 눌러 자기 화면에서 숨길 수 있습니다.
- **작성한 사람이 할 수 있는 것:** 자기 메시지를 **지우기**로 삭제할 수 있습니다.
- **계정 차단:** Firestore에 `banned` 컬렉션을 만들고, 문서 ID를 차단할 사람의 uid로 해서 문서를 추가합니다. uid는 메시지 문서의 `uid` 필드에서 확인할 수 있습니다. 차단된 계정은 메시지와 발자국을 더 이상 쓸 수 없습니다.
- **관리자가 할 수 있는 것:** 문제 있는 글은 Firebase 콘솔의 Firestore `messages` 컬렉션에서 직접 삭제합니다. 금칙어는 `js/filter.js`의 `BANNED` 목록에서 추가하거나 뺄 수 있습니다.

## 파일 구성

```
index.html             화면 구성
css/style.css          UI 스타일
js/main.js             메인 루프, 이동, 충돌, UI
js/world.js            지형, 나무, 발견 요소, 청크 생성·삭제
js/sky.js              하늘, 해·달·별, 시간, 날씨(비·안개), 반딧불이
js/controls.js         터치 조이스틱, 키보드, 마우스
js/audio.js            환경음·BGM·발소리 재생
js/traces.js           Firebase 발자국·메시지
js/account.js          익명·구글 로그인, 기기 간 이어 걷기
js/animals.js          사슴, 토끼, 새 떼
js/filter.js           메시지 금칙어 필터
js/config.js           Firebase 설정 (직접 채우기)
lib/                   Three.js r187, Firebase SDK 13 (번들)
assets/audio/          환경음·BGM (mp3)
firestore.rules        Firestore 보안 규칙
```

### 조정하기 쉬운 값

- **하루 길이:** `js/sky.js`의 `DAY_MS` (기본 20분)
- **날씨 바뀌는 주기:** `js/sky.js`의 `WEATHER_MS` (기본 6분)
- **숲 모양:** `js/noise.js`의 `SEED` (바꾸면 완전히 다른 숲이 됨)
- **시야·나무 밀도:** `js/main.js`의 `Q` (모바일과 PC 값이 따로 있음)
- **테스트용 주소:** 주소 뒤에 `?t=0.9`(밤), `?t=0.76`(노을), `?w=rain`, `?w=mist`, `?w=clear`를 붙이면 시간과 날씨를 고정할 수 있습니다.

### 사운드

`assets/audio`의 바람, 새소리, 풀벌레, 빗소리, 발소리, 효과음, BGM은 이 프로젝트를 위해 새로 합성한 음원입니다. 따로 표기해야 할 저작권이 없습니다. 다른 음원으로 바꾸려면 **같은 파일 이름의 mp3**로 덮어쓰면 됩니다. 새소리, 풀벌레, 바람, 비, BGM은 반복 재생되므로 끝과 처음이 자연스럽게 이어지는 파일이 좋습니다. CC0 음원은 Freesound(라이선스 필터: CC0)나 OpenGameArt에서 찾을 수 있습니다.
